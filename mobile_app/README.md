# Mobile Application Subsystem

Cross-platform Flutter application providing:
- Real-time IoT sensor telemetry and irrigation state toggling.
- Dual-mode disease detection (ESP32-CAM local query and mobile camera/cloud inference).
- Offline-capable diagnosis history with SQLite / IndexedDB persistence.
- Plant health diagnostic chatbot powered by Google Gemini.
- Protocol simulator for rapid offline development in `tool/esp32_simulator.dart`.
