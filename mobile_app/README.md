# Mobile Application Subsystem

Cross-platform Flutter application providing:
- Real-time IoT sensor telemetry and irrigation state toggling for the ESP32 Irrigation Node.
- Foliar disease detection via mobile camera photo capture and gallery image upload.
- Instant pathology diagnosis and agronomic prescriptions (chemical, biological, cultural).
- Offline-capable diagnosis history with cross-platform SQLite / Web IndexedDB persistence.
- Plant health diagnostic chatbot powered by Google Gemini.
- Protocol simulator for rapid offline development in `tool/esp32_simulator.dart`.
